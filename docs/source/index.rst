eudract-py
==========

Eudract-py is a Python library for searching and retrieving clinical trials
from the `EU Clinical Trials Register (EudraCT)
<https://www.clinicaltrialsregister.eu/about.html>`_.

It provides a simple interface to:

* search clinical trials by keyword and retrieve their full protocol details,
* fetch individual trials by their EudraCT number,
* download the complete register,
* cache results locally in a SQLite database.

.. note::
   This project is not affiliated with the European Medicines Agency (EMA).
   It is an independent, community-maintained client for the public EudraCT
   register.
